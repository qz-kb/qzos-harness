# QZOS 工作台预览

[English](README.md) | 中文

这个私有浏览器插件在现有 DSH 外壳中增加工作台、知识库、数字员工、连接器、技能、模板和成果目录。界面控件支持中英文，合成内容使用中文。原 DSH 工作窗口保留为默认首页和侧栏第一项“工作窗口”。QZOS 面板不替换原生 Session 引擎、输入区、工具、工作区导航或右侧面板。

## 使用方式

Web bundle 挂载 `ui-qzos`。移除或禁用这一配置行即可恢复上游界面。插件拥有 `qzos-*` 主面板和侧栏入口；浏览器内存保存跨页面的草稿、目录选择和模拟对话，刷新清空。员工卡片和详情进入原生工作窗口，插入结构化 `@员工`，不发送、不覆盖草稿、不改变已有消息；同一员工从目录重复进入不会重复插入。原生 `@` 菜单优先显示员工，支持部分名称和职责关键词匹配，保留原文件／对话引用。未选中会话时，只有一个工作区则打开该工作区的空白会话；否则先在原窗口选择工作区。模板只填入模拟工作台草稿，不自动发送。

按根目录 `.node-version` 使用 Node，通过 `pnpm dsh web --patch apps/web/tests/pin-browse-picker.overlay.yml` 启动。需要开发状态预览时，在浏览器控制台设置 `sessionStorage.setItem("qzos.preview", "1")` 并刷新；移除此键即可隐藏。普通页面显示演示数据标签，不显示开发控件。原生 DSH 控件仍执行其原有操作；只有 QZOS 新面板使用模拟数据。

## 模型影响

不发起模型请求，不产生 token 使用或 KV 缓存变化。员工入口复用原生草稿、导航和触发菜单服务。模拟员工引用提交时显示未接入说明并保留草稿；删除员工引用后可以继续普通 DSH 对话。进入空白原生会话可能调用已有 DSH 工作区流程，不运行模型或员工任务；目录操作未接 QZOS 业务 API 或凭据。

## 已知限制与后续工作

首轮面向桌面 Web，窄窗口支持折叠导航。上传、发布、外部授权、技能安装、文件生成和下载尚不可用；预览和选择不授予权限。真实身份、引用、计费和任务执行后续接入；Electron 未验证。
