# QZOS 资源页面预览

[English](README.md) | 中文

## 概述

这个私有浏览器插件为 DSH 增加知识库、数字员工、连接器、技能和模板。原生工作窗口仍是默认入口，承载所有会话；工作台和成果页已移除。

## 使用方式

Web bundle 挂载 `ui-qzos`，移除这一行即可恢复上游呈现。按根目录 `.node-version` 使用 Node，执行 `pnpm run dev:web --patch apps/web/tests/pin-browse-picker.overlay.yml --port 3081`；启动器参数须放在 Web 参数之前。

企业托管模式下，私有 Host 注入 `__QZOS_MANAGED_ACCOUNT__`。业务请求使用相对文档基址的 `_qzos/business` 与同源 Cookie，不从浏览器存储恢复业务凭据。HTTP 401/403 返回企业登录入口；退出经网关调用 `_qzos/logout`。注入 ID 仅选择呈现方式，访问权限由网关及业务后端校验。

知识库和员工页面依据现有 QZOS 客户端的 `qzos-pc/src/pages/application/layout/{kb,robot}.vue`、`application/kb/detail/`、`application/robot/setting.vue` 及其子视图还原。封面卡片、成员入口、员工头像与更多菜单、详情侧栏、新建字段和配置分组沿这些原页面；中文原文归语言字典，发布图标复用 QZOS 原资产。连接器、技能、模板继续沿 DSH 插件／自动化任务页面风格。

知识库页面通过原生 `useResource` 读取本机 QZOS 列表、配置、资料、分段和成员，新增／修改／删除、重命名、分段操作、成员授权／移交与检索沿原接口。写入成功后回读，失败保留表单并显示后端原因；不再生成模拟资料或检索结果。业务身份切换会卸载知识库页面并隔离资源地址，令牌只进入本机 API 请求头。模型选项取自 `/index/models`，保持后端 readiness 限制。员工、连接器、技能和模板均读取当前账号的真实 API。交互设施复用 DSH 原生弹窗、菜单和控件。

开头的员工引用用于绑定会话，不写入提交的问题正文，使纠错能够匹配原知识问题；输入框和剪贴板仍保留员工标签。

员工入口新建独立原生会话，以员工名命名并插入 `@员工`，不自动发送。空白输入框选择员工使用该会话；已有会话选择员工则新开会话，保留旧草稿。部分名称／职责匹配及原文件／对话引用保留。首次发送经私有 Host 适配器绑定会话；每轮新用户消息重新授权检索关联知识，仅将角色与片段写入普通消息。停用／暂停／退役员工、失效知识关联、外部工作流和检索失败均拒绝发送并保留草稿。新会话使用当前或唯一工作区。

<a id="model-experience"></a>
## 模型影响

### 业务操作

#### 模型看到的内容

此 UI 插件不增加 DSH 系统提示词或工具定义；可选的私有 Host 执行适配另行提供员工技能与插件工具。每轮用户输入前的上下文包含`employeeId`、角色和有权限的知识片段；DSH 记录这些上下文，并使用工作窗口所选模型执行。后端模型 ID、工作流密钥和登录令牌不进入模型输入。

#### Token 影响

用户主动发起学习和检索时可能消耗 QZOS 模型额度；首次角色和知识片段也会消耗 DSH 输入 Token；列表、登录和权限操作不增加 DSH 模型 Token。

#### KV 缓存影响

插件不构造 DSH 模型请求，也不改变其缓存结构。

<a id="known-limitations-and-deferred-work"></a>
## 已知限制与后续工作

- 知识库由 QZOS 后端复核权限，员工 Host 绑定与逐轮上下文已接入；本机合成知识的真实回答与逐轮检索追问已验证。已接入授权连接／调用记录、插件申请、技能详情／启停／共享／卸载及市场安装更新／签名离线包、模板创建员工。市场测试站尚未启用，真实签名分发仍待验证。覆盖桌面 Web 和窄窗口，Electron 未验证。

非托管预览指向本机 `qzos-login-test` 环境；企业托管模式使用部署网关。找回密码、生产端点配置、短信／邮件送达和微信服务商验证不在已验证范围。UI 本身不隔离 DSH 文件、会话或工具；托管部署须为每个用户提供独立 Host 和执行环境。

私有插件通过原生 shell overlay 挂载全屏登录／注册页，未登录时先显示该页；左侧不增加账号模块。登录后进入工作界面，退出或经服务端确认的过期回到登录页。此展示不新增 DSH Host 的多用户授权能力。

本机知识库验证环境包含独立 PostgreSQL、原安装结构及 ACL／版本迁移，已配置聊天和向量模型、Python／PDF 工具及私有上传。服务端沿现有 Python Workers 解析，浏览器不增加算法。资料状态弹窗按服务端允许操作接入复核、草稿保存、确认学习、重试、替换、额度继续和取消；写操作携带候选、修订号和幂等请求标识，成功后回读。新版本只接受一个原件，导入失败保留原请求供重提；解析完成不等于生效，学习完成前继续检索当前有效版本。

本机合成 XLSX 已验证上传、公式缺缓存人工修正、草稿保存回读、学习、失败重试恢复及取消。员工下一轮回答由第一版 17 日更新为第二版 23 日；取消第三版后仍检索第二版。后续已验证补额继续、未知用量确认、PDF／PPTX 学习，以及 PDF／PPTX／XLSX 纠错新版与精确来源；基础设施重试耗尽的服务端状态已修复。扫描 PNG／PDF 已用本机 Tesseract 真实识别，PDF 复核确认后学习并检索命中；图片沿现有直接学习路径，不外推所有版式与异常分支。

文件权限弹窗接入规则查询、主体候选和增改停用，沿服务端软删除保留历史。对外服务使用 `/kb.publish/knowledgeExternal`，开启前确认、保存后回读；仅改开关不要求模型就绪。规则增改停用、所有者保留、开关回读及未登录拒绝已有本机合成验证。

固定本机启动入口：工作区 `scripts/start-dsh-ui.sh` 转发到本插件跟踪的 `scripts/start-local.sh`。也可在仓库根目录执行 `bash packages/client/ui-qzos/scripts/start-local.sh`。脚本读取 `.node-version`，使用工作区 `.local/toolchains/node-v<版本>/bin`（需包含 Node 可执行文件和 `include/node` 开发头文件），沿官方 `dev:web` 先构建再启动，监听后续修改；构建失败停止，端口占用明确提示，不杀其他进程。默认地址为本机 3081，使用 `--no-open` 避免每次重启累积浏览器标签；复用已有预览页，按启动输出完成原 Host 认证。首次使用其他机器需准备对应 Node 发行包、pnpm、项目依赖和本机 QZOS 后端；运行环境、测试账号与密钥不入库。

### 开发备注

<details>
<summary>本机接入上下文</summary>

插件负责业务传输与原生资源注册。凭据及本机运行状态不进入 Git；实际验证与模型、解析配置缺项记录在 Product 原任务中。

</details>

员工管理读取完整配置，写入保留嵌套工作流及菜单图片。发布草稿、额度、状态和对话记录复用现有接口。本机合成验证覆盖创建、配置回读、浏览器保存、关闭状态发布项增改删及未登录拒绝。当前测试授权拒绝 API 发布，密钥生命周期成功路径未验证；网页／JS 公开链接、独立 iframe 嵌入及二维码 PNG 海报已接入，复用同源 QZOS 访客页；技能／插件绑定已沿现有接口接入。选择员工不自动发送。私有 Host 适配器持久保存员工／账号绑定，每轮新用户消息重新检查权限并检索。业务登录在 Host 内存授权；重启后刷新页面会重新校验已保存的业务会话并恢复 Host 授权，凭据失效则要求重新登录。启用可选私有执行适配后，DSH 原生回答及实际用量同时回写 QZOS。独立 Host／容器部署已实测跨账号文件、历史和终端拒绝；共享本机预览仍不提供此隔离，本机模型配置与合成知识回答已验证，不代表未接员工功能全部完成。

聊天隐藏员工上下文，只显示用户提问、回答及其知识来源引用。新检索消息使用私有上下文来源并沿原生聊天过滤；已有历史由注册文本规则识别完整旧员工数据封装，仅隐藏对应聊天行。Session 记录、模型输入和轨迹检查保持不变。

员工知识关联失效时默认保留原关联。设置中可明确重新绑定到非空选择，或确认移除全部关联；保存后回读员工并核对关联结果，失败保留表单。下一轮用户提问使用保存后的关联，移除后不再检索知识库。已有会话历史及引用仍保留。

已生效的结构化资料按服务端允许操作显示“纠错并创建新版”。纠错草稿绑定当前有效版本，保存并回读事实，沿现有复核／学习流程处理；旧版保留到新版学习完成。复核和搜索结果显示明确的页码、幻灯片或工作表／单元格坐标。搜索将表单 semantic 模式转换为 API 的 similar 模式；缺少位置时明确提示，不自行推断。

资料列表的“原件与生命周期”读取当前托管原件。下载通过凭据请求、禁止缓存与重定向，账号切换或关闭面板后丢弃未完成下载；历史公开 URL 不直接打开。编辑者可查看生命周期、修订号和生效窗口，按现有边提交草稿／复核／发布／归档；服务端开关与双人复核仍生效。操作后回读，结果未知时先刷新，不自动重发。撤权后的已有 Session 历史不由此入口擦除。

员工配置页明确回答使用工作窗口模型；仅保存的字段标注当前 DSH 不生效。技能／插件绑定沿现有接口操作，外部工作流不可启用或编辑；已有开启状态可关闭并沿原接口保存。温度通过私有请求钩子生效，优化／重排进入现有检索 API，均在下一轮读取；不改工作窗口模型和 DSH 核心。

当前私有页面增加服务端准备的 QA 文本及两列 CSV／XLSX 导入、学习／QA 状态、重试及预估读取；导入算法仍在 Python Workers。员工广场／共享、技能／插件绑定及原生会话的回答反馈弹窗调用当前 QZOS API。绑定仅在配置可选 Host 执行适配后生效。反馈弹窗属于根业务作用域，账号变更立即关闭，只读取当前账号最近 100 个已记录轮次。DSH 用量合计仅统计可信回执，未知用量单独提示。外部工作流编辑入口移除，保存配置保留，已启用的旧工作流可以关闭。对外 API 发布继续后置；扫描 PNG／PDF 的离线 OCR 已验证，外部工作流不做。公开分享仅使用发布公开标识，不含成员凭据或 API 密钥；JS 发布独立使用 type=2，访客预览不会打开内部员工会话。

公开分享需配套支持访客会话协议的 QZOS PC 静态端。本机验证复用 PC `05b225b` 的现有源码构建（未改 PC 源码）；旧静态包的发送失败不能靠生成链接解决。

托管模式通过 `publicVisitorOrigin` 指定独立公开访客站点；未配置时拒绝生成误指向私有网关的链接。原件与离线包下载使用同源网关 Cookie，不把业务凭据写入 URL。模板只允许启用的角色模板，不能借模板 ID 读取私有表单技能；创建后回读员工姓名和模型，模板不继承知识权限。

QA／CSV 预览为每份文档保留请求标识，提交重试沿用该标识。服务端对已完成请求直接回执，不再创建资料或学习任务；不同载荷及尚未完成的回执明确报错。

纠错弹窗仅提供自己拥有的知识库。发送前将请求号、目标库及纠错内容写入当前标签页的 sessionStorage，按后端、账号、员工及对话记录隔离。关闭重开弹窗或刷新会恢复该待确认请求，明确成功后清除；其他标签页及关闭浏览器标签页不属于此恢复范围。无法读取或保存恢复信息时显示提示并停止提交。同一内容保存响应丢失后重试保留请求号；修改内容或目标库产生新请求号。服务端重新校验所有权，复用现有持久导入回执去重已受理纠错。

旧记录以 `@员工` 开头时，仅当标签匹配当前员工名、剩余正文与记录中的知识来源原题完全一致，纠错弹窗才预填原题。历史记录保持原样，已有待确认请求仍恢复原提交内容；无法确认的文字保留供用户编辑，不自动截去。
